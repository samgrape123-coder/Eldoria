# ✨ Realms of Eldoria — The Wilds Awaken

**A magical fantasy adventure where exploration, ancient mysteries, and corrupted guardians await.**

## 🌿 About the Game

*Realms of Eldoria* is a browser-based fantasy adventure prototype set in an enchanted forest filled with magical crystals, mysterious creatures, and forgotten power.

Play as the **Wayfarer**, explore the wilds, collect aether shards, battle corrupted sentinels, and restore the forest's lost magic.

The current prototype uses HTML5 Canvas and JavaScript to render a 2D fantasy world with real-time movement, combat, particle effects, and a game interface.

## 🎮 Features

- **Fantasy World:** Explore a procedurally populated forest with trees, rocks, flowers, and magical clearings.
- **Character Movement:** Move freely through the world using keyboard controls.
- **Magic Combat:** Cast aether bolts to damage enemies.
- **Blink Ability:** Teleport a short distance to escape danger or reposition.
- **Healing Ability:** Restore health using aether energy.
- **Enemy AI:** Corrupted sentinels pursue the player and attack at close range.
- **Collectibles:** Gather glowing aether shards scattered throughout the forest.
- **Quest System:** Progress through *The Corrupted Clearing* quest.
- **Progression:** Earn experience, level up, and replenish your health and mana.
- **Game HUD:** Monitor vitality, aether, experience, quest progress, and collectibles.
- **Minimap:** View the surrounding world, enemies, and shard locations.
- **Visual Effects:** Enjoy magical projectiles, glowing crystals, particle bursts, and spell effects.
- **Pause and Restart:** Pause the adventure or return after being defeated.

## 🕹️ Controls

| Key / Input | Action |
|---|---|
| `W` `A` `S` `D` | Move |
| Arrow keys | Move |
| Mouse movement | Aim |
| Left-click | Cast an aether bolt |
| `Space` | Cast an aether bolt |
| `Q` | Blink forward |
| `E` | Restore health |
| `Esc` | Pause or resume |
| `Enter` | Rise again after defeat |

## 📜 Main Quest: The Corrupted Clearing

The ancient forest has fallen silent. Its roots are poisoned, its guardians corrupted, and its magic is fading.

Your mission is to:

1. Explore the enchanted forest.
2. Find and collect at least five aether shards.
3. Fight the corrupted sentinels.
4. Earn experience and increase your level.
5. Continue exploring the wilds and uncover their mysteries.

## 🚀 Getting Started

### Requirements

- A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.
- A keyboard and mouse for the best experience.

### Run Locally

1. Download or clone the project.
2. Locate the main HTML file.
3. Open the HTML file in your browser.
4. Click **Enter the Realm** to start playing.

No package installation or build step is required for the current standalone prototype.

## 🛠️ Technologies Used

- **HTML5** — Game structure and interface.
- **CSS3** — Styling, responsive layout, and visual effects.
- **JavaScript** — Game logic, movement, combat, enemy behavior, and progression.
- **HTML5 Canvas API** — Rendering the world, characters, particles, and effects.
- **Browser Animation APIs** — Real-time game loop and animation.
